# Plan Wdrożenia Inteligentnego Zarządzania Zadaniami (Task Refinement)

Celem jest nauczenie GAI, aby nie rzucała się do pracy "na oślep", lecz najpierw analizowała zadanie, dzieliła je na etapy (podzadania) i dopiero wtedy przystępowała do realizacji – dokładnie tak, jak robiłby to senior developer.

## 1. Modyfikacja Logiki Autonomicznej (`server.js`)
Obecnie, gdy GAI widzi nowe zadanie (`pending`), otrzymuje instrukcję "IMMEDIATELY start". Zmienię to na proces dwuetapowy:

*   **Krok 1 (Planowanie):** Instrukcja nakaże GAI najpierw sprawdzić, czy zadanie ma listę podzadań (`subtasks`). Jeśli nie – GAI będzie musiała użyć narzędzia `TASK_ACTION` z akcją `update`, aby dodać profesjonalny opis i checklistę kroków.
*   **Krok 2 (Wykonanie):** Dopiero gdy zadanie jest dobrze zdefiniowane, GAI otrzyma polecenie zmiany statusu na `in_progress` i rozpoczęcia pracy.

**Zmiana w kodzie:**
W sekcji obsługi `pendingTask` w `runAutonomousCycle`:
```javascript
focusInstruction = `CRITICAL PRIORITY: New task pending: "${pendingTask.title}".
1. ANALYZE: Does it have a clear breakdown (subtasks)?
2. REFINE: If not, FIRST use [[TASK_ACTION]] (update) to add a detailed description and a checklist of subtasks.
3. EXECUTE: Only then set status to 'in_progress'.`;
```

## 2. Aktualizacja Promptu Systemowego (`server.js`)
Dodam do `DEFAULT_SYSTEM_PROMPT_PL` (oraz `AUTONOMOUS_AGENT_PROMPT` jeśli jest używany) nową zasadę w sekcji "STANDARDY DZIAŁANIA":

*   **Nowa zasada:** "Przy nowych zadaniach ZAWSZE zaczynaj od planowania. Rozbijaj duże zadania na mniejsze podzadania (`subtasks`) i aktualizuj je w systemie. Pracuj iteracyjnie, odhaczając punkty z checklisty."

## 3. Weryfikacja Narzędzia `TASK_ACTION`
Upewnię się, że funkcja `parseTaskAction` i `db.updateTask` poprawnie obsługują pole `subtasks` (tablica obiektów `{id, title, status}`). Z analizy kodu UI (`TaskManager.tsx`) wynika, że obsługa już istnieje, więc backend musi tylko poprawnie przyjąć dane.

---

### Efekt końcowy dla Ciebie
Gdy napiszesz np. *"Zrób porządek w kodzie"*, GAI zamiast losowo zmieniać pliki:
1.  **Zaktualizuje zadanie:** Zmieni opis na "Refaktoryzacja i czyszczenie kodu".
2.  **Doda checklistę:**
    *   [ ] Analiza nieużywanych importów
    *   [ ] Formatowanie (Prettier)
    *   [ ] Usunięcie martwego kodu
3.  **Zacznie pracę:** Będzie wykonywać punkty po kolei, a Ty zobaczysz postęp na pasku zadań.
