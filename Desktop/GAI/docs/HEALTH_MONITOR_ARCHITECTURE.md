# Health Monitor Architecture\n\n## Overview\nComprehensive health monitoring system for GAI autonomy process, extending existing backendWatchdog.mjs functionality.\n\n## Components\n\n### 1. Heartbeat Tracker\n- Monitors autonomy tick frequency from .gaios/backend.log\n- Detects idle states (>5 min without tick)\n- Tracks tick rate trends (normal: ~30-60s intervals)\n\n### 2. Error Rate Monitor\n- Parses loop_breaker events from logs\n- Counts consecutive failures\n- Triggers alert if >3 loop_breakers in 10 min\n\n### 3. Process Watchdog (PID Monitoring)\n- Extends backendWatchdog.mjs PID tracking\n- Monitors Ollama (port 11434), backend (8080)\n- Checks memory usage per process\n\n### 4. Auto-Restart Logic\n- Graceful restart: SIGTERM -> wait 5s -> SIGKILL\n- Restart delay: 2s between attempts\n- Max restarts: 3 per 10 min (then alert)\n\n## Integration Points\n\n### Existing Files\n- /scripts/backendWatchdog.mjs - base watchdog\n- /.gaios/backend.log - autonomy tick logs\n- /.gaios/watchdog.log - watchdog events\n- /.gaios/ollama.log - Ollama server logs\n\n### New Scripts to Create\n1. scripts/healthMonitor.mjs - main monitor\n2. scripts/heartbeatChecker.mjs - tick analyzer\n3. scripts/autoRestart.mjs - restart logic\n\n## Alert Mechanisms\n1. Log file entries (.gaios/health_alerts.log)\n2. Desktop notification (osascript)\n3. Optional: Telegram webhook\n\n## Configuration\n{\n  \"tickIntervalMax\": 300000,\n  \"loopBreakerThreshold\": 3,\n  \"loopBreakerWindow\": 600000,\n  \"maxRestartsPerWindow\": 3,\n  \"restartWindow\": 600000\n}\n\n## Implementation Phases\n1.
