# Implementacja Systemu Nauczania GAI (Teacher-Student Loop)

## Cel
Zwiększenie skuteczności lokalnego modelu AI (GAI) poprzez optymalizację promptów, dodanie przykładów (few-shot learning) i mechanizmu dynamicznej korekty błędów, symulując proces "nauczania" przez bardziej zaawansowany model.

## Plan Wdrożenia

### Krok 1: Stworzenie "Zeszytu Ćwiczeń" (Few-Shot Examples)
Stworzenie zestawu idealnych przykładów interakcji, które pokażą modelowi dokładnie, jak ma myśleć i używać narzędzi.
1. Utworzenie pliku z przykładami (User Input -> Thought Process -> Tool Call).
2. Przykłady obejmą: obsługę plików, komendy shell, zarządzanie zadaniami.

### Krok 2: Przepisanie "Podręcznika" (System Prompt Optimization)
Aktualizacja pliku `data/prompts/autonomous_prompt.txt`.
1. Zastąpienie ogólnych instrukcji ścisłym algorytmem postępowania.
2. Wymuszenie struktury odpowiedzi (Chain-of-Thought).
3. Dodanie "Zeszytu Ćwiczeń" bezpośrednio do promptu systemowego.

### Krok 3: Implementacja "Pętli Korekcyjnej" (Feedback Loop) w `server.js`
Modyfikacja logiki w `runAutonomousCycle`, aby system dynamicznie reagował na błędy modelu.
1. Wykrywanie typowych błędów (brak narzędzi, zł format JSON).
2. Wstrzykiwanie "Podpowiedzi Nauczyciela" (Hint) do kolejnego zapytania w przypadku błędu (np. "Nie zwróciłeś narzędzia w poprzednim kroku. Użyj [[TASK_ACTION]]").

### Krok 4: Weryfikacja (Egzamin)
1. Restart systemu `gaios`.
2. Uruchomienie testowego zadania autonomicznego (np. prostego audytu pliku), aby sprawdzić, czy model poprawnie używa nowych instrukcji.
