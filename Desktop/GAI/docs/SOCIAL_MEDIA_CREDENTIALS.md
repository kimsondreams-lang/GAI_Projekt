# Social Media API Credentials Setup Guide\n\n## Twitter (X) API\n1. Go to https://developer.twitter.com/\n2. Create developer account and apply for access\n3. Create new project and app\n4. Generate API Key, API Secret, Access Token, and Access Token Secret\n\n## Pinterest API\n1. Go to https://developers.pinterest.com/\n2. Create developer account\n3. Create new app in developer portal\n4. Generate API Key and note Board ID\n\n## Facebook (Meta) API\n1. Go to https://developers.facebook.com/\n2. Create Meta Developer account\n3. Create new app and add Facebook Login product\n4. Generate Page Access Token with publish_pages permission\n\n## Security Notes\n- Never commit credentials to version control\n- Use environment variables in production\n- Rotate credentials periodically
